    Class CryptoAio

    Dependency container: stores, signers, wallets, hooks, plugins and a shared driver pool. Separate new CryptoAio() instances are fully isolated (use one per tenant).

    close

    • close(): Promise<void>

      Closes the root container (R34): runs the close of every native client that crypto-aio/native handed out (a failing one is logged by code and skipped), then closes the pooled drivers. Its handles and native() then fail with INVALID_TRANSITION. A scope's close() does nothing; scopes share their root's pool.
