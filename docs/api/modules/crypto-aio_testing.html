    Module crypto-aio/testing

    crypto-aio/testing: a deterministic, network-free test kit (fake chain, fetch and clock, a crash-injecting store, a ready-made environment) and the store contract suites that any OperationStore, LockManager, SequenceStore or CursorStore implementation must pass.
