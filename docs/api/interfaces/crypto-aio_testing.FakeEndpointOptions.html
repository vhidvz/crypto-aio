    forkAbove?: number

    A single endpoint lying about blocks: above this height its block reads (fake_getBlock, fake_getBlockHash) serve a private fork, with other hashes and none of the chain's transactions, and fake_getTransaction does not see transactions mined there. Heights, nonces, balances and finality stay honest.
