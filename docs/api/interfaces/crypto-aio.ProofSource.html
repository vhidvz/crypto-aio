    Interface ProofSource

    Finalized-state checks behind proven verdicts; implementations use quorum reads. Lesson 18: only a definitive negative proof answers "no". Every other RPC error (state or history not available, pruned data, indexing in progress, a non-definitive error) throws a retryable ProviderError('PROVIDER_UNAVAILABLE'), which decides nothing.
