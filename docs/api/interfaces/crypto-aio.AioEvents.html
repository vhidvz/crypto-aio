    nonce.gap

    "nonce.gap": {
        blockingOperationId?: string;
        chain: string;
        expected: string;
        namespace: string;
        network: string;
        operationId: string;
    }

    A submitted Operation has waited past the grace period while the chain's pending nonce (expected) is below its own. At-least-once: a monitor reports each (Operation, expected) once, but that memory is per process and bounded, so the same gap is reported again after a restart, by another process, or once it was forgotten.
