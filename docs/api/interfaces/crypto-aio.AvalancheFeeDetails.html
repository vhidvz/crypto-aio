    Interface AvalancheFeeDetails

    FeeEstimate.details of the avalanche fee kind. The X-Chain burns a fixed fee per transaction (static); the P-Chain prices gas since the Etna upgrade (dynamic). Amounts are in nAVAX (9 decimals).
